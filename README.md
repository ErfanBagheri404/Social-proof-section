# Social proof section

![Design preview for the Social proof section challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Social proof section** challenge - a responsive component built from the provided design.

**Live demo:** https://erfanbagheri404.github.io/Social-proof-section/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Social-proof-section.git
cd Social-proof-section
```

Open `index.html` in a browser. Nothing to install or compile.
